# OpenWorld repo templates

Starter repos for creative work that isn't code. Copy a folder into a new GitHub repo
(or, once published, use GitHub's **Use this template** button), fill it in, then add the
repo on your OpenWorld profile.

| Template | For |
|---|---|
| [theater](theater/) | Plays, devised work, productions |
| [dance](dance/) | Choreography, performance, movement research |
| [visual-art](visual-art/) | Painting, drawing, sculpture, installation, photography |
| [music](music/) | Albums, EPs, scores, sound pieces |

Each has an `openworld.yml` (what OpenWorld shows) and a folder layout. Delete what you don't
need — nothing is required except what you want to show. Big video and audio belong on
YouTube, Vimeo, SoundCloud, Bandcamp, etc.: link them in `openworld.yml`, or attach final
files to a GitHub **Release** (up to 2 GB per file).

See [docs/MANIFEST.md](../docs/MANIFEST.md) for every option.
